# 决策：搜索源改用网盘搜索站，通用引擎降级为兜底

日期：2026-10-08
状态：已定方向，待配置具体的网盘搜索站

## 结论（两句话）

1. **直接用通用搜索引擎爬关键词找资料，实测效果不行**——搜出来的是工具站和官网落地页，不是资料。
2. **网盘搜索站作为 hunt 的主力搜索源**，接入 `[[hunt.engine]]` 自定义引擎接口；分工是"网盘搜索当眼睛，爬虫当手"。

## 实验数据（2026-10-08，公司网络，bing+baidu 双引擎）

| 关键词 | 搜索结果 | 深挖结果 | 收获 |
|---|---|---|---|
| 绘画 AI提效 claude | 在线绘画工具站（sketchpad/kleki/速写板） | - | 0 |
| AI绘画教程 网盘 | IBM/DeepMind/Kimi 官网 | - | 0（相关性门槛正确拦截了 IBM 的 3 个 PDF） |
| 板绘 | 课程平台（蓝铅笔/萌绘）+ B站 | 蓝铅笔、萌绘各深挖 8 页内页，全在登录墙后 | 仅 B站路径产出：板绘素描全集 p01（3.5MB mp4） |
| 笔刷 | 素材商店（爱给网/笔刷库/58pic） | 商品页无直链 | 0 |
| PS笔刷 百度网盘 | Adobe/微软商店官网；CSDN 博客被反爬拦（521） | - | 0 |

### 失败原因归纳

1. **通用引擎的语义理解跑偏**：把"PS笔刷"当 Photoshop 产品词，返回官网和商店页
2. **真资源页有反爬**：CSDN 等博客站对非浏览器请求 403/521
3. **资源站的下载在登录墙/详情页后**：课程平台（蓝铅笔）、素材商店（爱给网）公开页面 0 直链，深挖两层也挖不到
4. **百度对数据中心/公司 IP 间歇弹安全验证**（时好时坏，已优雅降级）

### 意外发现：唯一稳定产出的是 B 站

视频类资源链路全程畅通：搜索能搜到 → yt-dlp 全支持 → 自动下载成功。
视频类关键词（课程/教程）当前即可用；文件类（笔刷/图包/电子书）必须换搜索源。

## 新方案：网盘搜索站 + 爬虫分工

```
keywords.txt → watch → hunt（搜索源 = 网盘搜索站）
                          ↓
              分享链接 + 提取码（爬虫负责：批量收集/去重/关键词校验/定时增量）
                          ↓
              _links 或 _hunt/<关键词>/分享链接.md 索引
                          ↓
              人工转存（近期）→ 百度网盘开放平台转存 API 自动转存（终局）
```

爬虫不退役的部分（这些正是搜索工具给不了的）：

- **批量去重与校验**：50 条结果里筛掉重复/死链/货不对板，提取码自动配对
- **定时增量**：关键词经 hook 写入 keywords.txt，watch 每轮自动搜新词（SQLite 记录不重复）
- **索引沉淀**：带时间戳的 Markdown 索引，失效重搜只需清对应记录
- **转存自动化**（终局）：百度网盘开放平台有分享转存接口，链接自动进网盘

## 落地结果（2026-10-09 完成）

调研路径：候选站全是 JS 渲染的 SPA → 翻开源聚合器 PanHub（github.com/joyce677/panhub）的插件源码 → 拿到两个上游搜索引擎的调用方式 → 做成 hunt 内置引擎。

- **pansearch（盘搜, pansearch.me）**：已接入。Next.js 数据接口（buildId + search.json），返回成品分享链接+提取码，直进 `分享链接.md` 索引。实测"板绘"18 条/"笔刷"17 条命中。
- **qupansou（去盘搜, funletu）**：已实现但暂不默认启用——API 域名 v.funletu.com 证书不匹配（2026-10 观测），接口半死。它恢复了在 config 的 engines 里加回去即可。
- **PanHub 本体**：线上实例 API 有密码门/版本旧，不直接依赖；但它的 config/plugins.ts 里有 20+ 上游站清单（duoduo/fox4k/huban/jikepan/panyq/susu/zhizhen…），以后想扩搜索源就从这里抄。

验证数据：板绘 10 条 + 笔刷 15 条分享链接落 `data/sync/_hunt/<关键词>/分享链接.md`，含夸克/阿里/百度盘与提取码，转存即得。

这类站的原理也在源码里得到印证：PanHub 主数据源是 TG 80+ 网盘资源频道 + 第三方插件站，Cheerio 解析 HTML——与我们 linkhub 引擎同构。自建索引（吃 TG 频道）是后续可选的大增量。
